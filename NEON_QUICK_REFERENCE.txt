================================================================================
                              5-MINUTE SETUP
================================================================================

1. CREATE NEON ACCOUNT (1 minute)
   └─ Visit https://neon.tech
   └─ Click Sign Up
   └─ Use GitHub, Google, or email

2. CREATE NEON PROJECT (2 minutes)
   └─ Go to https://console.neon.tech
   └─ Click "+ New Project"
   └─ Name: "blurdetect"
   └─ Click "Create Project"
   └─ Wait for creation (1-2 mins)

3. GET CONNECTION STRING (30 seconds)
   └─ In Neon Console, click "Connection string"
   └─ Copy the PostgreSQL connection string
   └─ Format: postgresql://user:password@host/blurdetect

4. UPDATE .env (30 seconds)
   └─ Open .env file in project root
   └─ Find: DATABASE_URL=postgresql://neon_user:password@ep-xyz.us-east-1.neon.tech/blurdetect
   └─ Replace with your Neon connection string from step 3
   └─ Save file

5. INSTALL & RUN (1-2 minutes)
   └─ pip install -r requirements.txt
   └─ python init_db.py
   └─ python app.py
   └─ Visit http://localhost:5000

================================================================================
                         CONNECTION STRING FORMAT
================================================================================

YOUR STRING (from Neon Console):
  postgresql://neon_user:abcd1234xyz@ep-cool-lake-123456.us-east-1.neon.tech/blurdetect

BREAKDOWN:
  postgresql://  ← Protocol
  neon_user      ← Username (usually "neon_user")
  abcd1234xyz    ← Password (from Neon)
  @              ← Separator
  ep-cool-lake-123456.us-east-1.neon.tech  ← Host (endpoint from Neon)
  /blurdetect    ← Database name

UPDATE .env FILE:
  1. Open /vercel/share/v0-project/.env
  2. Find line starting with: DATABASE_URL=
  3. Replace entire line with your connection string
  4. Save file

  WRONG: DATABASE_URL=postgresql://neon_user:password@ep-xyz...
  RIGHT: DATABASE_URL=postgresql://neon_user:abcd1234xyz@ep-cool-lake-123456.us-east-1.neon.tech/blurdetect

================================================================================

1. CLONE REPOSITORY

================================================================================
                          TROUBLESHOOTING
================================================================================

ERROR: "Connection refused"
  CAUSE: Wrong DATABASE_URL
  FIX:
    1. Go to Neon Console
    2. Copy connection string again
    3. Paste into .env
    4. Check for typos or extra spaces

ERROR: "Authentication failed"
  CAUSE: Wrong password
  FIX:
    1. In Neon Console, go to Settings
    2. Reset password
    3. Update .env with new password

ERROR: "relation 'users' does not exist"
  CAUSE: Database not initialized
  FIX:
    $ python init_db.py

ERROR: "too many connections"
  CAUSE: Multiple Python processes
  FIX:
    1. Stop all running Flask instances
    2. $ python app.py

SLOW DATABASE QUERIES:
  FIX:
    1. In Neon Console, upgrade compute size
    2. Check Monitoring tab for slow queries

================================================================================
                           NEON CONSOLE TIPS
================================================================================

MONITOR YOUR DATABASE:
  1. Go to https://console.neon.tech
  2. Click your project
  3. View:
     • Monitoring → Active connections
     • Monitoring → Database size
     • SQL Editor → Test queries

RUN SQL QUERIES:
  In Neon Console → SQL Editor:
  
  SELECT * FROM users;           -- View all users
  SELECT COUNT(*) FROM images;   -- Count images
  SELECT * FROM system_events ORDER BY timestamp DESC LIMIT 10;

RESET PASSWORD:
  1. Settings → Security
  2. Click "Reset password"
  3. Create new password
  4. Update .env

SCALE RESOURCES:
  1. Settings → Compute
  2. Choose compute size
  3. Changes applied automatically
