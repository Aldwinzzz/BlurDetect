How it works:
  1. User registers → SHA256 password hashing
  2. User saved to Neon database
  3. Token created with itsdangerous
  4. Email sent via Gmail SMTP
  5. User clicks email link
  6. Token validated
  7. is_verified = True
  8. User can login
