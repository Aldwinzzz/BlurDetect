# BlurDetect - Quick Start (2 Minutes)

## Installation & Run

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Initialize Database
```bash
python init_db.py
```

### 3. Start Application
```bash
python app.py
```

**Done!** Visit `http://localhost:5000`

---

## First Steps

### Create Account
1. Click **Register**
2. Enter username, email, password
3. Check email for verification link
4. Click the verification link
5. Log in with credentials

### Upload Image
1. Click **Upload** in dashboard
2. Drag and drop an image OR click to browse
3. Click **Analyze Image**
4. Wait for analysis complete

### View Results
- See detected blur type with confidence score
- View explanation of what caused the blur
- Compare all 5 detection models
- Check which model was most accurate

### Explore Features
- **Dashboard:** See your statistics
- **History:** View all past analyses
- **Events:** Track your activities
- **Profile:** Manage account settings
